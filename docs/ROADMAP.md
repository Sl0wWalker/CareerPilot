# Roadmap

## Current focus: sustainable v1

- Maintain privacy, truthfulness, and supervised submission guarantees.
- Improve real ATS reliability using sanitized fixtures and measured success rates.
- Reduce setup friction and strengthen local diagnostics.
- Keep API, plugin, migration, and release contracts stable.

## Next

- Real-user beta feedback and prioritized defect reduction.
- Greenhouse, Lever, Ashby, and Workday compatibility matrices.
- Resume quality benchmarks and hallucination regression suites.
- Reproducible Windows release artifacts.

## Later

- Optional integrations that preserve a free local workflow.
- Production hosting only after local proof-of-work and explicit privacy review.

Ideas outside these priorities belong in GitHub discussions or issues and are not delivery
commitments.
