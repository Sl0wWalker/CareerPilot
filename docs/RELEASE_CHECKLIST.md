# CareerPilot v1 Release Checklist

- [ ] Working tree contains no secrets, personal data, databases, or generated resumes.
- [ ] Backend and frontend versions are `1.0.0`.
- [ ] Alembic upgrades a clean database to head.
- [ ] Backup creation and restore validation pass.
- [ ] Backend unit and integration tests pass.
- [ ] Frontend tests, lint, type checking, and production build pass.
- [ ] First-run onboarding works with keyboard navigation.
- [ ] Resume import, job matching, document generation, and dry-run automation smoke tests pass.
- [ ] Docker images build and health checks pass.
- [ ] Changelog, user guide, developer guide, deployment guide, and API docs are current.
- [ ] GitHub Actions pass on the release commit.
- [ ] Release commit is pushed before creating the annotated `v1.0.0` tag.
