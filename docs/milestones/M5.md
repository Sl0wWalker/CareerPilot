# M5 — Explainable Job Matching & Scoring

## Outcome

CareerPilot now compares a normalized job with the verified Career Knowledge Base and
persists an explainable match. The engine produces an overall score, confidence,
recommendation, gaps, hard blockers, evidence, and an eight-component breakdown.

## Architecture

`MatchingService` owns scoring. `MatchingRepository` owns persistence. The matching
router exposes calculation, retrieval, and settings endpoints. No scoring logic lives
in routes or React components.

The deterministic engine scores:

- verified skills;
- relevant experience;
- seniority;
- education;
- location preferences;
- work authorization and explicit sponsorship restrictions;
- keyword overlap;
- semantic similarity.

Semantic similarity reuses the M3 provider embedding interface. If embeddings are
unavailable, the engine records a low-confidence neutral semantic component rather
than failing the complete match.

## Explainability and safety

Each component includes its score, weight, confidence, explanation, matched evidence,
and missing evidence. Explicit no-sponsorship language becomes a separate hard blocker
when the profile requires sponsorship. An LLM does not select the final numeric score.

## API

- `POST /jobs/{job_id}/match`
- `GET /jobs/{job_id}/match`
- `GET /matching/settings`
- `PUT /matching/settings`

Weights are configurable but must contain all components, remain non-negative, and sum
to one.

## UI

Job details now include Match Analysis, Gap Analysis, Score Breakdown, confidence,
eligibility blockers, and Recommendation Insights.

## Deferred

Resume tailoring, cover letters, application answers, browser automation, and
submission remain outside M5.
