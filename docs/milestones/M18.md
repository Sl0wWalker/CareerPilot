# M18 — Global Platform, Mobile Experience, and Next-Generation AI

## Outcome

M18 adds a coherent global and mobile foundation without introducing a second,
disconnected client stack. The existing React application is now an installable
progressive web app (PWA), while FastAPI exposes regional preferences, mobile
device registration, supervised notification delivery, and privacy-aware model
routing.

## Architecture

- `GlobalPreference` stores locale, region, timezone, currency, accessibility
  choices, and jurisdiction-specific job-market rules.
- `ModelRoutingPolicy` selects local-first or explicitly approved cloud fallback
  per AI task and data privacy class.
- `MobileEndpoint` represents PWA, iOS, or Android notification-capable devices.
- `NotificationDelivery` provides a durable queue boundary. Actual APNs, FCM, or
  Web Push adapters remain deployment-specific and optional.
- The PWA service worker caches only the static application shell. API responses
  and personal data are deliberately excluded.

## Mobile strategy

The React/Vite interface is the shared mobile foundation. It is installable on
modern desktop and mobile browsers and supports offline shell loading. A future
native wrapper may reuse the API and shared schemas after real mobile workflows
are validated.

## Global deployment

1. Run the API and database in the target region.
2. Serve the web build over HTTPS with `manifest.webmanifest` and the service
   worker at the origin root.
3. Configure locale-specific job connectors and legal/application questions in
   `regional_job_rules`.
4. Keep restricted AI tasks on Ollama. Cloud fallback must be explicitly enabled
   per task.
5. Add a delivery adapter for Web Push/APNs/FCM; workers consume queued
   `NotificationDelivery` rows and record provider receipts.
6. Use the existing sync conflict model for mobile writes. Clients should queue
   mutations while offline and replay them after reconnection.

## Accessibility

The mobile workspace reads operating-system reduced-motion and contrast
preferences and stores user overrides. Responsive layouts, semantic labels,
keyboard operation, and visible online/offline state remain release gates.

## Deferred intentionally

- Native App Store binaries
- Paid push-notification providers
- Automatic cross-border data transfer
- Silent cloud fallback for sensitive AI tasks
- Caching API responses containing personal data
