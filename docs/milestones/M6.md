# M6 — AI Resume Tailoring and Document Generation

M6 adds an evidence-backed document domain on top of the verified Career Knowledge Base,
M3 AI providers, and M5 matching results.

## Capabilities

- Immutable, job-specific resume and cover-letter versions.
- Deterministic ATS-safe resume assembly with matched-skill prioritization.
- Optional AI rewriting constrained to supplied verified evidence.
- Keyword coverage and missing-keyword reporting.
- Screening-answer drafts with sensitive-question review gates.
- Approval states and editable document content.
- Version comparison.
- Local PDF and DOCX export.

## Safety model

AI output is always stored as a draft. Canonical career facts are never changed. Every generated
document retains the evidence supplied to the model. Sponsorship, work authorization, salary,
demographic, clearance, criminal-history, and signature questions are never guessed.

## API

- `POST /documents/jobs/{job_id}/resume`
- `POST /documents/jobs/{job_id}/cover-letter`
- `POST /documents/jobs/{job_id}/screening-answers`
- `GET /documents`
- `PATCH /documents/{document_id}`
- `GET /documents/{document_id}/export?format=pdf|docx`
- `GET /documents/compare/{left_id}/{right_id}`

## Extension points

`DocumentService` accepts the existing `AIProvider` interface. Templates are persisted separately
from content, allowing future HTML/CSS renderers and additional ATS-safe layouts without changing
the document schema.
