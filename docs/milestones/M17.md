# M17 — Autonomous Career Platform & Intelligence Hub

## Outcome

CareerPilot now provides a proactive intelligence layer over the existing job,
matching, document, tracking, platform, marketplace, and enterprise modules. It
adds strategy planning, opportunity monitors, skill-demand forecasts, market
insights, recruiter-engagement summaries, configurable agents, notification
channels, and autonomy governance.

## Architecture

The intelligence module is orchestration-only. It does not duplicate job
discovery, matching, marketplace workflows, enterprise agent runs, or platform
events. Monitors publish platform events; agents declare capabilities that map
to existing modules and installed workflows.

Core resources:

- `CareerStrategy` stores user-owned, time-bounded plans.
- `OpportunityMonitor` stores criteria and cadence for proactive searches.
- `SkillForecast` stores evidence-backed current/projected demand.
- `MarketInsight` stores sourced, confidence-scored market observations.
- `AutonomousAgentConfig` governs reusable platform capabilities.
- `NotificationChannel` establishes local and cross-device delivery targets.

## Approval boundaries

External writes are never silently authorized. Application submission,
messaging, profile changes, and document publication always require explicit
approval. The default autonomy level is `recommend`; `prepare` may create local
drafts, while `execute` remains constrained by the same approval gates.

## User interface

The Career Intelligence workspace contains:

1. Career Intelligence Hub
2. Strategy Planner
3. Opportunity Monitor
4. Agent Dashboard

## Extension points

- Marketplace agent packs and workflows supply new capabilities.
- Platform events allow monitors and notifications to remain decoupled.
- Enterprise policies can further restrict autonomous behavior.
- Sync and integration modules can deliver cross-device notifications.
- Forecast evidence can later be recomputed from normalized job snapshots.
