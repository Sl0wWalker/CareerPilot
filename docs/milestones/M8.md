# M8 — Application Tracking, Analytics & Workflow Management

## Outcome

CareerPilot now carries prepared applications into a persistent lifecycle workspace. Users can
move applications through a Kanban board, inspect immutable timeline events, retain notes and
contacts, schedule follow-ups and interview placeholders, record outcomes, and review local
funnel analytics.

## Architecture

- `models/tracking.py` defines applications, immutable events, notes, contacts, follow-ups, and
  interview placeholders.
- `repositories/tracking.py` owns persistence and timeline queries.
- `services/tracking.py` owns lifecycle timestamps and aggregate metrics.
- `api/tracking.py` exposes lifecycle, related-resource, analytics, and JSON portability APIs.
- `TrackingWorkspace.tsx` provides the responsive dashboard, metrics, Kanban workflow, timeline,
  notes, contacts, tags, filters, and export entry point.

Applications reference the existing profile, job, and optional automation run. This preserves
traceability from discovery and matching through document creation, automation, and outcome.

## Workflow

Supported states are `draft`, `preparing`, `ready`, `submitted`, `recruiter_screen`, `interview`,
`offer`, `rejected`, `withdrawn`, and `archived`. Status changes create immutable events and
automatically maintain applied, first-response, and closed timestamps.

## Analytics

The local analytics service calculates funnel counts, response/interview/offer rates, rejection
counts, and average time to first response. No telemetry or cloud analytics dependency is used.

## Portability

`GET /applications/export` produces versioned JSON. `POST /applications/import` validates imported
records and associates them with the local profile. Personal information remains local and
excluded from Git.

## Future extension points

- Calendar notification adapters can consume follow-up and interview placeholders.
- Company/contact intelligence can enrich existing contact records.
- Additional charts can consume the stable analytics response without changing lifecycle logic.
