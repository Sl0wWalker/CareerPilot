# M10 - Version 1 Polish, Packaging, and Launch

M10 turns the M0-M9 engineering build into a coherent v1 release candidate.

Delivered:

- first-run onboarding with a persistent completion state;
- consolidated Start & Help workspace with live diagnostics;
- local-first privacy, supervised-automation, and recovery guidance;
- visible keyboard focus treatment and responsive onboarding layouts;
- aligned backend and frontend `1.0.0` package versions;
- changelog, end-user guide, developer guide, architecture diagram, deployment guide,
  and auditable release checklist;
- documented packaging boundary: native scripts and Docker Compose are supported in
  v1; Tauri desktop installers are a post-v1 extension.

No cloud telemetry or mandatory paid service was introduced.
