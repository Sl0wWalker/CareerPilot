# M13 — AI Career Coach & Interview Intelligence

## Outcome

CareerPilot now turns verified career evidence, job context, application history, and
user goals into practical coaching workflows. The module adds career goals,
company-specific interview questions, mock interview sessions, deterministic STAR
coaching, skill-gap learning plans, long-term roadmaps, and weighted offer comparisons.

## Architecture

- `models/coach.py` owns the coaching domain and history.
- `repositories/coach.py` isolates persistence.
- `services/coach.py` owns coaching rules and reuses the existing `AIProvider`.
- `api/coach.py` exposes thin FastAPI routes.
- `CoachWorkspace.tsx` provides Career Coach, Interview Prep, Mock Interview, Learning
  Plan, and Career Roadmap entry points.

AI-generated questions receive only verified Career Knowledge Base evidence and optional
job context. Provider failure falls back to deterministic questions. Answers are never
written into the verified profile. STAR coaching uses transparent scoring and records
the profile evidence referenced by an answer.

## API

- `GET /coach/dashboard`
- `GET|POST /coach/goals`
- `POST /coach/interview/questions`
- `POST /coach/interview/sessions`
- `POST /coach/interview/sessions/{id}/responses`
- `GET|POST /coach/learning-plans`
- `POST /coach/roadmaps`
- `POST /coach/offers/compare`

## Safety and limitations

- Coaching and salary/offer comparisons are decision support, not guarantees or
  professional financial advice.
- Learning resources remain provider-neutral and default to free/open-source options.
- Candidate claims must be grounded in verified evidence.
- Live salary datasets can be added later behind a replaceable research provider.
