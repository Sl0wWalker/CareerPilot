# M3 — AI Profile Intelligence & Knowledge Enrichment

## Goal

Add optional AI assistance to the verified Career Knowledge Base without allowing
model output to bypass user review.

## Architecture

- `AIProvider` defines health, model discovery, structured generation, and embeddings.
- Ollama is the default local provider. Gemini and OpenAI-compatible adapters are optional.
- Versioned prompt templates live outside application logic.
- `AIProfileService` creates summaries, reviewable suggestions, embeddings, and semantic results.
- AI suggestions remain pending until explicitly approved or rejected.
- AI keys are read only from the local environment and are never persisted.

## Data

The migration adds `ai_settings`, `ai_suggestions`, and `profile_embeddings`.
SQLite stores vectors as compact float arrays. The service boundary permits a future
vector database without changing API contracts.

## User experience

The AI workspace reports provider health, launches profile analysis, drafts summaries,
offers semantic profile search, presents approval cards, and edits non-secret provider
preferences.

## Safety boundaries

- Model output never writes directly to canonical profile tables.
- Only supported approved suggestion types can add canonical skills or achievements.
- Prompts instruct providers to use only verified profile facts.
- Secrets and candidate prompts are not logged.

## Deferred

Job matching, discovery, resume tailoring, cover letters, browser automation, and
application submission remain out of scope.
