# M1 — Core Domain and Career Knowledge Foundation

## Outcome

M1 establishes the single-user CareerPilot career profile as a structured aggregate.
It stores personal details alongside experience, education, projects, skills,
certifications, achievements, and job preferences.

## Design decisions

- UUID identifiers make records portable across future storage backends.
- The profile is an aggregate root; related career records are deleted with it.
- Repository code owns persistence, service code owns single-profile business rules,
  and FastAPI routers translate HTTP requests and errors.
- Pydantic create, update, and read contracts are separate from SQLAlchemy models.
- Alembic migrations are the authority for runtime schema changes.
- Profile creation accepts nested career records so imported data can later be
  reviewed and persisted as one transaction.

## Intentionally deferred

- AI and Ollama integration
