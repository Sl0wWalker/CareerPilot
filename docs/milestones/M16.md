# M16 — AI Marketplace, Automation Studio & Ecosystem Expansion

M16 extends the M14 platform contracts with a local-first marketplace and a
supervised workflow composer. Supported content includes prompt packs, resume
templates, workflows, job-source connectors, plugins, and agent packs.

Packages use semantic versions and stable, beta, or canary channels. Publishing
validates explicit permissions and dependencies and creates a deterministic
SHA-256 signature over the canonical manifest. Installation is owner-scoped and
refuses activation when dependencies are missing.

Marketplace packages are data, not implicitly trusted executable code. Runtime
plugins continue to use the M14 entry-point contracts. The workflow engine
supports action, AI, condition, approval, and integration nodes. Graphs reject
duplicate or dangling references; execution defaults to dry-run and pauses at
approval nodes. Actions are recorded as sandboxed rather than executing
arbitrary package code.

The API provides package discovery, publishing, installation, reviews,
uninstallation, workflow creation, execution, and approval. The web application
adds Marketplace, Automation Studio, Package Manager, and Publisher Console
views. Sample packages demonstrate an ATS resume pack and a supervised
application workflow.
