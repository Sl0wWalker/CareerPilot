# M4 — Intelligent Job Discovery

## Outcome

CareerPilot can define and synchronize job sources, normalize listings into one schema,
deduplicate them, search and filter locally, favorite roles, save searches, define future
search schedules, and request AI-assisted relevance analysis against the verified career
profile.

## Provider architecture

All external sources implement a small `JobProvider.fetch()` contract. Built-in providers
cover Greenhouse, Lever, Ashby, Workday-compatible JSON, generic JSON feeds, and RSS.
Provider responses are converted into a common intermediate record before persistence.
Network access occurs only during an explicit source sync.

## Normalization and deduplication

The ingestion service:

1. Removes HTML and normalizes whitespace.
2. Normalizes location and workplace classification.
3. Normalizes salary range, currency, and period.
4. Creates searchable text from title, company, location, and description.
5. Deduplicates first by source/external ID and then by a stable content fingerprint.
6. Retains the raw source payload for audit and future parser improvements.

## Search and saved definitions

Local SQL search supports text, company, location, workplace type, employment type,
minimum salary, favorites, pagination, and deterministic recency ordering. Saved searches
store a query and filter object. Scheduled searches store cadence definitions only; no
background scheduler was added in this milestone.

## AI relevance

Relevance analysis reuses M3's provider abstraction. It sends only the selected job and
verified profile evidence, validates structured output, clamps scores to 0–100, and stores
strengths, gaps, and a concise explanation. This is guidance, not the future deterministic
matching score.

## User interface

The Job Discovery workspace includes:

- Search and workplace filters
- Favorites-only view
- Job cards and detail view
- AI relevance action and evidence
- Original-listing link
- Saved-search definitions

## Extension points

- Background execution can later consume `ScheduledSearch` definitions.
- Full-text search can migrate from SQL `LIKE` to SQLite FTS5 without API changes.
- New sources implement the same provider contract.
- M5 can add requirement extraction and explainable deterministic ranking.

## Intentionally out of scope

Resume tailoring, cover letters, application answers, browser automation, application
submission, and background scheduling remain out of scope.
